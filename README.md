# Multi-FX-Pedal
I wanted to build a Multi-FX bass pedal for myself with an MCU, and an analogue preamp circuit attached.

I am thinking of including distortion, chorus, delay, and reverb effects. The idea is to use a Teensy 4.1 
as the MCU to process the signals.

The circuit layout and the controls are yet to be planned for the Teensy controlled FX. I will be 
using a reference circuit for my preamp circuit design and I will simulate using LTSpice with .wav files.
All of these resources will be added to this repository.
